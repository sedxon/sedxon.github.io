Política de privacidad

Mis tareas UNAM · Última actualización: 13 de octubre de 2026

Qué hace la aplicación

Lee las tareas y foros del aula virtual SIGEUN de la persona que la ejecuta y crea eventos con esos plazos en un calendario de Google que la propia aplicación crea ("Aula Virtual UNAM").

Datos de Google a los que accede

Solo el permiso https://www.googleapis.com/auth/calendar.app.created: crear un calendario secundario y administrar los eventos de ese calendario. La aplicación no puede leer, modificar ni borrar tus otros calendarios, contactos, correos ni ningún otro dato de tu cuenta.

Dónde se guardan los datos

Todo se guarda únicamente en la computadora de quien usa la aplicación: el permiso de Google (token_google.json), la sesión del aula virtual y la lista de tareas. La contraseña del aula, si se guarda, queda en el Administrador de credenciales de Windows. No existe ningún servidor del desarrollador: ningún dato se envía al desarrollador ni a terceros.

Uso de los datos

Los datos se usan solo para mostrar las tareas y mantener actualizado el calendario. No se venden, no se comparten y no se usan para publicidad ni para entrenar modelos de IA. El uso de datos recibidos de las API de Google cumple la Política de datos de usuario de los servicios de las API de Google, incluidos los requisitos de uso limitado.

Cómo borrar tus datos o quitar el permiso

  • Quita el acceso en myaccount.google.com/permissions.
  • Borra el calendario "Aula Virtual UNAM" desde Google Calendar.
  • Borra la carpeta de la aplicación de tu computadora.
